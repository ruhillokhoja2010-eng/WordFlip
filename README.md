# WordFlip — GitHub / Render

Загрузите файлы из этой папки в корень репозитория GitHub.

Render → New → Static Site → подключите репозиторий.
Build Command: оставить пустым (если требуется, `echo ready`).
Publish Directory: `.`

Откройте HTTPS-адрес сайта на iPhone в Safari → Поделиться → На экран «Домой».

## Важно
- Работает офлайн после первой успешной загрузки сайта.
- Данные аккаунтов хранятся локально в браузере, а не на сервере.
- Режим игры вдвоём в этой версии по-прежнему использует ручной обмен WebRTC-кодами. QR-подключение ещё не реализовано.
- Значок на экране iPhone статический: iOS не предоставляет PWA доступ к автоматической смене значка вместе с другими приложениями.
- Для обновления закешированных файлов измените CACHE в sw.js.
